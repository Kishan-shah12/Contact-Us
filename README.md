# 3D Responsive Contact Us Landing Page 🚀

A high-performance, full-screen video-background landing page and interactive contact form built with **React, TypeScript, Vite, and Tailwind CSS**.

![Preview](https://d8j0ntlcm91z4.cloudfront.net/user_38xzZboKViGWJOttwIXH07lWA1P/hf_20260602_150901_c45b90ec-18d7-42ff-90e2-b95d7109e330.mp4)

## ✨ Features

- **Full-Screen 3D Video Background**: Seamless responsive video framing with responsive viewport scaling and ambient contrast layering.
- **Glassmorphic Navbar**: Floating pill bar with `backdrop-blur-md`, custom 3D dual-gradient geometric logo mark, and responsive layout.
- **Micro-Animations**:
  - Continuous hand wave (`👋`) animation with natural keyframe oscillation.
  - Staggered organic floating social buttons (GitHub, LinkedIn, Facebook) that pause smoothly on hover.
- **Smart Contact Form**:
  - Name, Email, and expandable Message textarea.
  - Multi-select interactive service tags chips (`Website`, `Mobile App`, `3D & Motion`, `E-Commerce`, etc.).
  - Direct live email routing to `jnkishansah@gmail.com` via FormSubmit API.
- **Interactive 3D Notification (`Notification3D`)**:
  - Cursor- and touch-responsive 3D perspective tilt physics (`rotateX`, `rotateY`).
  - Dynamic holographic light sheen glare following pointer movement.
  - Multi-layer `translateZ` depth with floating glowing checkmark sphere and dispatched inbox status beacon.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Tooling**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v3](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Google Fonts (*Inter* & *Instrument Serif*)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Kishan-shah12/Contact-Us.git

# Navigate to project directory
cd Contact-Us

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

```bash
npm run build
```

The production output will be generated in the `dist/` directory.
